# ReadmeCraft

An Android (Kotlin + Jetpack Compose) studio for designing, previewing, and exporting a decorative GitHub Profile `README.md`, initialized from the `nazimunaeem/nazimunaeem` profile template.

## Features

- **Live Decorative Preview**: Renders your profile hero banner, animated typing sub-banner, social/view badges, canvas-drawn decorative dividers, About Me prompts, grouped tech stack badges, and theme-matched GitHub analytics widget previews.
- **Full Profile Customizer**: Edit GitHub username, display name, tagline, location, animated typing lines, all 8 GitHub profile About Me prompts, social handles, and searchable tech stack badges.
- **Decorative Studio**: Switch between color palettes (*Tokyo Night*, *Dracula*, *Radical*, *Catppuccin*, *GitHub Dark*, *Emerald Matrix*), header banner styles, decorative dividers, `shields.io` badge styles, and widget toggles.
- **One-Tap Markdown Export**: Generates valid, copy-ready `README.md` Markdown with clipboard copy, Android Share Sheet export, and DataStore persistence.
